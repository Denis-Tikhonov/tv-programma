# ТВ программа (PWA)

Офлайн-приложение программы телепередач (EPG).

**Версия:** 1.2.0

## Возможности

- Предустановленные источники: 1lot.tv и gabbarit
- Добавление своих URL (с историей)
- Выбор периода: 1 / 3 / 7 дней
- Каналы, избранное, фильтр
- Поиск по названию, описанию, категории, каналу (с историей)
- Цветовое выделение вчера / сегодня / завтра
- Полные карточки передач
- Дата загрузки и индикатор свежести источника

## Стек

Чистый HTML + CSS + Vanilla JS. Без фреймворков.

## Деплой

GitHub Pages.  
GitHub Action каждый день обновляет `epg/1lot.xml.gz`.

## Локальный запуск

```bash
npx serve .
# или
python -m http.server 8080
```

Не открывайте через `file://` — будет CORS.
