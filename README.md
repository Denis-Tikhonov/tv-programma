# ТВ программа

Локальная PWA-телепрограмма.  
Предустановленные источники обновляются автоматически через GitHub Actions.  
Можно добавлять свои ссылки вручную.

## Возможности

- 2 предустановленных источника (в будущем до 4)
- Ручное добавление любого EPG по ссылке
- Выбор периода: 1 / 3 / 7 дней
- Избранные каналы
- Поиск по названию / жанру / описанию
- Офлайн-работа после загрузки
- Установка как PWA

## Публикация на GitHub Pages + автообновление EPG

### Шаг 1. Создайте репозиторий

1. Зайдите на [github.com](https://github.com) и войдите в аккаунт.
2. Нажмите зелёную кнопку **New** (или **+** → New repository).
3. Название, например: `tv-programma`
4. Оставьте репозиторий **Public**.
5. Нажмите **Create repository**.

### Шаг 2. Загрузите файлы проекта

Самый простой способ для новичка:

1. На странице нового репозитория нажмите **uploading an existing file**.
2. Перетащите **все файлы и папки** из архива `tv-programma` (включая папку `.github`).
3. Внизу напишите commit message: `первый коммит` и нажмите **Commit changes**.

Альтернатива через Git (если умеете):
```bash
git clone https://github.com/ВАШ_ЛОГИН/tv-programma.git
cd tv-programma
# скопируйте сюда все файлы проекта
git add .
git commit -m "первый коммит"
git push
```

### Шаг 3. Включите GitHub Pages

1. В репозитории перейдите в **Settings** → **Pages** (слева).
2. В разделе **Source** выберите:
   - Branch: `main`
   - Folder: `/ (root)`
3. Нажмите **Save**.
4. Подождите 1–2 минуты. Сверху появится ссылка вида:
   `https://ВАШ_ЛОГИН.github.io/tv-programma/`

### Шаг 4. Настройка автоматического обновления EPG (GitHub Action)

Файл уже лежит в проекте: `.github/workflows/update-epg.yml`

Он будет:

- Каждый день в 06:00 UTC скачивать свежий EPG с 1lot.tv
- Кладёт его в папку `epg/1lot.xml.gz`
- Делает коммит и пушит изменения

**Что нужно сделать один раз:**

1. Перейдите во вкладку **Actions** вашего репозитория.
2. Если GitHub спросит разрешение — нажмите **I understand my workflows, go ahead and enable them**.
3. Справа найдите workflow **Update EPG**.
4. Нажмите **Run workflow** → **Run workflow** (чтобы проверить прямо сейчас).
5. Подождите 1–2 минуты. В логах должно быть написано, что файл скачался и закоммитился.

После этого каждый день файл будет обновляться сам.

### Шаг 5. Проверка

1. Откройте ваше приложение по ссылке GitHub Pages.
2. Перейдите в «Источники».
3. Нажмите **Загрузить** у источника «1lot.tv (основной)».
4. Выберите период и дождитесь загрузки.

## Структура важных папок

```
tv-programma/
├── .github/
│   └── workflows/
│       └── update-epg.yml     ← автообновление EPG
├── epg/
│   ├── 1lot.xml.gz            ← сюда Action кладёт файл
│   └── backup.xml.gz          ← второй источник (пока заглушка)
├── css/
├── js/
├── index.html
├── manifest.json
└── sw.js
```

## Полезные советы

- **Ручной запуск обновления**: Actions → Update EPG → Run workflow
- **Добавить второй источник**: отредактируйте файл `update-epg.yml` (раскомментируйте строки) и добавьте второй пресет в `js/app.js`
- **Файл слишком большой**: позже можно добавить в Action обрезку по дням (я помогу, когда будете готовы)
- **Ошибка 403 / 429 при скачивании**: 1lot.tv иногда ограничивает частоту. В Action уже стоят `--retry`
